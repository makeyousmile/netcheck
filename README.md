# NetCheck — Мониторинг доступности IP и портов с оповещениями в Telegram

Полнофункциональный легковесный сервис на **Golang** для периодического мониторинга сетевой доступности IP-адресов и портов с современным веб-интерфейсом и мгновенными оповещениями в **Telegram**.

---

## 🚀 Основные возможности

1. **Веб-интерфейс управления**:
   - Добавление, редактирование, удаление и приостановка мониторинга любых `IP / хост` и `порт`.
   - Настройка индивидуального интервала проверки (в секундах) и таймаута для каждого хоста.
   - Отображение текущего статуса:
     - 🟢 **UP** (Доступен, с измерением времени отклика в мс)
     - 🔴 **DOWN** (Сбой с выводом точной ошибки соединения)
     - 🟡 **ОЖИДАНИЕ / ОТКЛЮЧЕН**
   - Кнопка мгновенной проверки (⚡ *Проверить сейчас*).
   - Поиск и фильтрация по списку целей.

2. **Оповещения в Telegram**:
   - **Умное отслеживание перехода состояний**: если сервис работал (`UP`), а затем стал недоступен (`DOWN`) — программа немедленно отправляет сообщение в Telegram.
   - Защита от спама: если сервис уже упал, повторные алерты на каждую проверку не дублируются.
   - Опциональное уведомление о восстановлении связи (когда сервис снова поднялся, с расчетом времени простоя).
   - Кнопка *«Проверить отправку»* прямо в веб-интерфейсе для проверки валидности токена бота и Chat ID.

3. **Журналирование (Логирование)**:
   - Все проверки, сбои, переходы состояний и отправки уведомлений пишутся:
     - В стандартный вывод (консоль).
     - В файл логов (`data/netcheck.log`).
     - Во встроенный онлайн-просмотрщик в веб-интерфейсе с автоскроллом и кнопкой очистки.

4. **Полная автономность**:
   - Написано на стандартной библиотеке Go.
   - Веб-интерфейс полностью вшит внутрь исполняемого файла через `embed`. Не требует сторонних сборщиков или Node.js.
   - Все настройки и список целей сохраняются в локальные JSON-файлы в папке `data/`.

## 🛠️ Запуск и использование

### 1. Быстрый запуск

Запустите уже скомпилированный бинарник:

```bash
cd /root/netcheck
./netcheck -port 8088
```

Или запустите через `go run`:

```bash
cd /root/netcheck
go run main.go -port 8088
```

### 2. Параметры командной строки

| Флаг | Описание | По умолчанию |
|------|----------|--------------|
| `-port` | Порт веб-интерфейса | `8088` (или из `config.json`) |
| `-data` | Путь к директории хранения данных и логов | `./data` |
| `-token` | Telegram Bot Token (опционально) | из `config.json` |
| `-chat` | Telegram Chat ID (опционально) | из `config.json` |

После запуска откройте в браузере:
👉 **`http://<IP_сервера>:8088`**

## 🤖 Настройка Telegram-бота

1. Откройте в Telegram диалог с **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`, укажите имя и username для бота.
3. Скопируйте полученный **Bot Token** (вид `123456789:AA...`).
4. Нажмите `/start` в диалоге с созданным ботом.
5. Чтобы узнать свой **Chat ID**, напишите боту **[@userinfobot](https://t.me/userinfobot)** (он сразу напишет ваш цифровой `Id`).
   - Если хотите слать в группу/канал: добавьте бота в группу и укажите ID группы (например, `-100123456789`).
6. В веб-интерфейсе NetCheck перейдите на вкладку **«Настройки Telegram»**, вставьте Token и Chat ID и нажмите **«Проверить отправку»**.
7. Нажмите **«Сохранить настройки»**.

## ⚙️ Автозапуск через Systemd

1. Скопируйте файл сервиса:
   ```bash
   cp /root/netcheck/netcheck.service /etc/systemd/system/
   ```

2. Перезагрузите конфигурацию systemd и включите автозапуск:
   ```bash
   systemctl daemon-reload
   systemctl enable --now netcheck
   ```

3. Проверка статуса:
   ```bash
   systemctl status netcheck
   ```
