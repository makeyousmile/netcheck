Настройки Telegram Уведомлений

Когда IP:порт работал, а затем стал недоступен (DOWN), бот немедленно пришлет оповещение в Telegram!

Получите у @BotFather в Telegram.
Ваш личный Chat ID (узнать у @userinfobot) или ID группы/канала (бот должен быть добавлен в группу).
Параметры по умолчанию
Инструкция Telegram
  1. Откройте Telegram и найдите бота @BotFather.
  2. Отправьте команду /newbot и задайте имя и username боту.
  3. Скопируйте полученный HTTP API Token и вставьте в поле слева.
  4. Напишите что-нибудь своему новому боту (команду /start).
  5. Чтобы узнать свой Chat ID, напишите боту @userinfobot — он пришлет ваш Id.
  6. Нажмите кнопку «Проверить отправку» для подтверждения.
